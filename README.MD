# Student Management System

A console-based Student Management System built using Python.

## Features

- Add student data
- View all students
- Search student by roll number
- Edit student data
- Delete student data
- Calculate student result
- Calculate total marks and percentage
- Assign grades
- Show Pass/Fail result
- Store student data using JSON
- Load saved data automatically when the program starts
- Input validation for roll numbers and marks

## Technologies Used

- Python
- JSON
